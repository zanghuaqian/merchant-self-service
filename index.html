演示已覆盖的 PRD 要点

商户身份识别 4.1

  • App：登录 Token 静默获取商户号与产品线
  • 公众号：完整商户号（6-8 位）+ 预留手机号验证码绑定，服务端保存 OpenID ↔ 商户号
  • 一个微信可绑定多个商户号，默认使用上次查询的商户并支持切换
  • 未绑定不阻断，降级至受限首页

结算信息与结算规则 新增

  • 结算卡：类型（对公/对私）、账户名与卡号脱敏、归属银行
  • 结算规则：结算周期、日切时间、自动提现、预留金额、出款服务类型（随心提/安心提/交班提）
  • 与诊断结论联动：命中结算或卡异常时同步高亮

诊断引擎 4.2

  • P0/P1（风控、合同、资质）同时诊断；命中异常则阻断 P2/P3；否则继续结算/出款/分账/退款
  • 命中阻断异常即终止后续查询（明细标记「未执行」）
  • 全部正常返回「未发现异常」+ 安抚文案

解决方案配置 4.3

  • 资质过期 → 内嵌真实资质更新页（sass.shengpay.com）
  • 卡异常 → 结算卡变更页（settlecard.shengpay.com）
  • 批次出款失败（银行维护/渠道风控等）→ 提示失败原因并转人工
  • 未开自动提现 → 知识库指引 + 结算设置
  • 风控调单（有未处理记录）→ 跳转调单详情自助处理
  • 合同未签约 → 跳转电子合同签约页完成签署
  • 风控冻结 / 渠道异常 → 转人工并附原因

反馈与转人工 4.4

  • 退出诊断报告时弹出「已解决 / 未解决」，埋点含商户号/流水号/报告链接/反馈结果
  • 转人工自动生成诊断快照（流水号、7 项结果、用户操作）
  • 「其他问题」直接排队并同步商户信息

游客与绑定引导 4.5

  • 点击诊断按钮下发绑定引导图文消息
  • 输入完整商户号 → 带出预留手机号 → 短信验证码校验
  • 绑定关系写入服务端，成功后自动进入完整功能

异常与边界 第 7 节

  • 诊断超时（>5 秒）→「网络繁忙，是否转人工？」
  • 多异常并存 → 按阻断优先级展示，其余折叠
  • 线下业务线 → 暂未开通并自动转人工
使用说明
1. 每个场景左侧为演示控制台（非产品界面）：可切换商户后台数据状态（资质过期、卡异常、批次出款失败、风控冻结、多异常、正常、超时）与公众号绑定状态，切换后重新发起诊断即可查看对应分支。
2. 控制台底部实时输出埋点日志，对应 PRD 第 6 节指标口径。
3. 页面中的红色灯泡图标为产品标注，鼠标悬停可在右侧查看该功能点的产品逻辑说明。
4. 纯静态页面，双击 HTML 即可打开，无需构建与联网（图标字体缺失不影响功能）。
